# 미적분Ⅰ 모의 중간고사 제작 킷 (양정고 양식)

다른 AI(또는 사람)가 이 폴더만 받아서 지금까지와 같은 품질로 시험지 세트를 만들고 채점할 수 있도록 정리한 템플릿입니다. 1~9회 시험지가 모두 이 엔진으로 만들어졌습니다.

한 회차는 파일 세 개로 나갑니다.

- **시험지** (8쪽, A4): 학교 시험지 PDF의 벡터 바탕 위에 문항을 얹은 것.
- **정답 및 채점기준** (5~6쪽): 정답표, 서답형 채점기준, 문항별 풀이·출처·난도·변형 포인트·오답 설계.
- **서답형 답안지** (1쪽, A4 세로): 학생 기재란, 초검·재검 칸.


## 3. 한 회차 만들기

```bash
python3 new_round.py r10                 # rounds/r10 생성 (example_r8을 출발점으로 복사)
cd rounds/r10
# content3.py, sold.py, sol3.py 수정
python3 build3.py exam.pdf               # 시험지
python3 sol3.py sol.pdf                  # 정답 및 채점기준
python3 ans3.py ans.pdf                  # 서답형 답안지
```

출력 파일 이름은 `미적분1_중간고사_{n}회_시험지.pdf`, `_정답및채점기준.pdf`, `_서답형답안지.pdf`로 맞춥니다.

### 3-1. `content3.py` 형식

```python
PTS = [4.0]*4 + [4.2]*4 + [4.4]*2 + [4.5]*2 + [4.7]*3 + [4.9] + [5.2]*2   # 합 80
Q[1] = r"""문항 본문 ... 값은?{PT}""", ["1", "2", r"\dfrac32", "4", "5"]
Q[8] = r"""...다음 조건을 만족시킨다.""" + COND([('가', r"..."), ('나', r"...")]) + r"""...의 값은?{PT}""", [...]
Q[15] = r"""...""" + BOGI([('ㄱ', r"..."), ('ㄴ', r"..."), ('ㄷ', r"...")]), ['T:ㄱ', 'T:ㄴ', 'T:ㄱ, ㄷ', 'T:ㄴ, ㄷ', 'T:ㄱ, ㄴ, ㄷ']
Q[16] = r"""...그림과 같다.""" + FIG('fig16', 130) + r"""...{PT}""", [...]
ANS = {1: 3, 2: 1, ...}                         # 1~5
S1 = r"""단답형 본문""" ; S1S = [(r"(1) 물음", "3점"), (r"(2)", "3점"), (r"(3)", "4점")]
S2 = r"""서술형 본문""" ; S2S = [(r"(1)", "2점"), (r"(2)", "4점"), (r"(3)", "4점")]
```

- 수식은 `\( \)`(인라인), `\[ \]`(가운데 별도 줄). 긴 극한·분수식은 인라인에 두지 말고 별도 줄로 뺀다.
- 본문 텍스트의 `<`, `>`는 `&lt;`, `&gt;`로 쓴다(수식 안은 그대로 써도 됨).
- 큰 분수 안의 작은 분수는 `\dfrac`이 아니라 `\frac`(또는 `\tfrac`)로 써야 크기가 맞다. 반대로 인라인 분수는 `\dfrac`.
- 선택지: LaTeX 문자열(`\( \)` 없이). 텍스트 선택지는 `'T:'` 접두어.
- `{PT}` 자리에 `[4.2점]`이 들어간다.
- r-문자열 안의 HTML 속성은 작은따옴표: `<span class='nw'>…</span>`(줄바꿈 금지).
- 조건 박스 라벨 없이: `COND([('', r"...")])`.

### 3-2. 쪽 배치 (고정)

`build3.py`의 `PAGES`가 원본 시험지와 같은 위치에 문항을 놓습니다.

| 쪽 | 왼쪽 단 | 오른쪽 단 |
|---|---|---|
| 1 | 안내문 아래 1, 2 | 3, 4 |
| 2 | 5, 6 | 7 |
| 3 | 8 | 9, 10 |
| 4~7 | 11, 13, 15, 17 | 12, 14, 16, 18 |
| 8 | 단답형 안내 + 단답형 1 | 서술형 안내 + 서술형 1 + 수고하셨습니다 |

한 문항이 단을 넘치면 문항을 줄이거나 식을 별도 줄로 나눕니다. 빌드 후 `blocks.json`에 각 블록의 위·아래 좌표가 나오므로 넘침 여부를 확인할 수 있습니다(쪽 아래 경계 약 776pt).

### 3-3. 그림

```python
exec(open('figs_head.py').read())          # plt, axes(ax, xlim, ylim), 수식 글꼴 라벨
fig, ax = plt.subplots(figsize=(2.6, 2.3)); axes(ax, (-3, 4), (-2, 4))
ax.plot(...); ax.text(1, 2, 'y=f(x)')       # ASCII 글자·숫자·()=-는 한글 수식 글꼴로 자동 변환
fig.savefig('fig16.svg', bbox_inches='tight', pad_inches=0.02)
```

열린 점은 `mfc='white'`, 닫힌 점은 검은색. 수식 글꼴에 `|`, `^`, `√`, 그리스 문자가 없으므로 필요하면 Tinos로 따로 그립니다(`rounds/`의 예시 참고).

### 3-4. `sold.py`, `sol3.py`

- `sold.py`의 `make(src)`는 문항마다 `(풀이, 출처, 원본 난도, 변형 포인트, 변형 후 난도, 오답 설계)`를 돌려줍니다.
- `sol3.py`의 `S1`, `S2`는 서답형 정답·채점기준입니다. 단계마다 `------ [n점]`을 붙입니다.
- 서술형 채점 원칙(정답지 하단에 인쇄됨): 결과만 쓰고 근거가 없으면 해당 단계 점수 없음, 계산 실수로 최종값만 틀리면 마지막 단계만 감점.

## 4. 출제 규칙 (지금까지 확정된 것)

- **구성:** 선택형 18문항(80점) + 단답형 1(10점, (1)(2)(3) 3/3/4점, 답만) + 서술형 1(10점, 2/4/4점, 과정 서술).
  - 1~17번과 서술형: 부교재 문항 변형.
  - 18번과 단답형: 외부 문항(EBS·학력평가).
- **범위:** 함수의 극한, 연속, 미분계수, 미분가능성, 도함수, 접선. **극대/극소, 평균값 정리, 적분은 출제하지 않는다.**
- **제외 문항:** 부교재 거리 a²−1 문항(B59), 역함수와 교점 3개 문항.
- **외부 문항은 회차 간 절대 중복 금지** → `db/외부문항_사용기록.md`를 확인하고 사용 후 기록. 부교재 문항은 중복 허용.
- **난도 배치:** 계산량·길이까지 고려한 오름차순.
  - 1~2쪽(1~7번)은 박스 없는 간단한 계산.
  - 3쪽부터 부교재 고난도 문항.
  - 변형 강도는 3→4→5쪽 갈수록 세게: 특수→일반, 상수를 미지수로, 경우 늘리기, 계산량 늘리기. 17번이 가장 강하다.
  - (가)(나) 조건이 긴 문항을 앞쪽에 두지 않는다.
- **그래프:** 회차마다 그림 문항을 1개 이상 넣는 것을 선호.
- **정답 분포:** 선택형 정답 번호 ①~⑤가 각 3~4번.
- **검증:** 모든 정답을 sympy로 확인하고, 해가 유일한지(다른 경우가 배제되는지) 반드시 확인한다. `rounds/*/verify*.py` 예시처럼 남겨 둔다.

## 5. 학생(응시자)에게 결과를 알릴 때

응시자가 직접 시험을 보므로 **채팅에 문제 내용, 정답, 보기 진위, 풀이를 절대 쓰지 않는다.** 새 회차를 알릴 때는 구성·난도 같은 집계 정보만 말한다. 정답은 정답 PDF에만 둔다.

## 6. 채점

1. **OMR 판독:**
   - 스캔을 **300dpi 이상**으로 확대해서, 보기 칸 안에 인쇄된 번호와 칠한 칸을 문항마다 대조한다.
   - 축소본을 눈으로 세다가 한 줄씩 밀려 읽은 사고(7회 2번)가 있었다.
   - 스캔에 `/Rotate`가 있으면 `show_pdf_page(..., rotate=-page.rotation)`로 바로 세운다.
2. **답안지 표시:** `mark.py`를 회차 폴더로 복사해서 아래를 고친다.
   - 좌표: 표의 가로선·세로선은 픽셀 투영으로 찾는다. 초검 칸 가운데 x는 약 494~497pt.
   - 점수, 코멘트.
   - 실행: `python3 mark.py 스캔.pdf` → `graded.pdf`.
3. **성적표:** `report.py`의 `MARK`(OMR), `SA`(소문항별 득점), 감점 내역을 고친다.
   - 감점 내역은 f-string 안이라 `\`는 `\\`, `{ }`는 `{{ }}`로 쓴다.
4. 결과 파일:
   - `output/채점/성적표_{n}회_….pdf`
   - `output/채점/서답형답안지_채점_{n}회_….pdf`

## 7. 기타

- **시행일 변경:** `build3.py`의 `make_background()`에서 `'7월 11일(토) - 1교시'`를 찾아 바꾸는 줄을 수정하고, `sol3.py`의 `시험일자`도 같이 바꾼다.
- **복사본 느낌(선택):** `python3 photocopy.py exam.pdf exam_복사본.pdf [농도]`. 농도 기본값은 32이고, 숫자가 클수록 흐리다.
- **전문항 시험지:** `engine/build_all.py`. 부교재 전체를 난도순으로 자동 배치하고, 쪽수는 가변이다.
- **박스 선 두께:** Chromium은 0.75pt 미만 테두리를 0.75pt로 올려 그린다. 그래서 `thin_boxes()`가 PDF 단계에서 원본 양식과 같은 0.36pt로 낮춘다.
