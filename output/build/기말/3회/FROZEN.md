# 3회 고정본 (2026-11-07 사용자 확정: "3회차 셋 완벽히 저장")

3회는 4회부터의 본보기다. 이 폴더와 출력 PDF 6개는 고치지 않는다. 새 회차는 이 폴더의 `build3.py`·`sol3.py`·`compare.py`·`checkpart.py`·`render3.js`를 복사해 쓴다.

## 지문 확인
- `python3 지침/freeze.py check 3회` → `OK (고정본과 같음)`이면 저장소 파일·출력·빌드 재료가 그날 그대로다.
- `manifest.json`에 3회 저장소 파일, 측정 폴더(`공동출제/풀이/측정_3회A–H`), 출력 PDF, 저장소 밖 재료의 sha256이 있다.

## 다시 빌드하려면 (저장소 밖 재료)
- `기말/fonts/`: 상용 글꼴이라 저장소에 없다(한컴바탕·굴림·한컴 수식 글꼴 등). 파일 이름과 지문은 `manifest.json`의 `external`에 있다. 올려 준 글꼴 묶음에서 다시 꺼낸다.
- `기말/src/form2.pdf`: 학교 양식, 저장소 `template/src/form2.pdf`와 같은 파일.
- `기말/node_modules/`: katex 0.19.1, playwright-core 1.64.1.
- 끝맺음 이모티콘 그림은 `3회/assets/end_emo.svg`(저장소 안). 없으면 글자 이모티콘으로 바뀐다.

## 3회에서 정한 값 (4회부터 그대로, front.md 0-9)
- 머리글 정보 줄: 8.5pt·장평 105%·낱말별 위치(2026-2 중간 픽셀 대조), 끝맺음: 한컴바탕 23pt 진하게·이모티콘 그림, 서답형 줄 13.6pt·소문항 사이 1.5pt.
- 그림: 수식 글꼴 하나, 뾰족한 촉을 축 끝 4% 밖에.
- 측정: 20문항 모두 작년 기말 같은 번호 ±1.5 안(측정_3회A–H), 문구만 고친 문항은 `wording_edits.json`.
- 문제 글 감별(실제 3개 + 3회): 두 판정자 모두 3회를 45%로 고름(무작위 25%).
