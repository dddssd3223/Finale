## 1. 18문항 예상 시간 합계

## 2. 가장 어려운 문항 3개
- **18번**: 유리함수꼴 g의 불연속점 개수와 극한 존재 조건을 합쳐 근의 구조(√r=r)를 이끌어내야 함
- **16번**: |f(x)-x-m|의 교점 개수 함수에서 불연속점이 2개인 경우(N=0, M=0, M=-N)를 빠짐없이 나눠야 함
- **15번**: 합성함수 극한에서 이차함수 꼭짓점의 특수성을 알아채고 경계 m=0을 판단해야 함
  (13번도 비슷한 수준. 6번은 본문이 깨져 있어 난도를 정확히 평가할 수 없음)

## 3. 유형 분류
- **문장은 짧은데 생각이 필요한 문항**: 3번(증가함수 + 사잇값 정리), 12번(OA=AB에서 중점을 알아채기), 15번, 18번
- **계산이 길어서 오래 걸리는 문항**: 13번(g 결정 → 접선 두 개 → 교점 → 넓이), 14번(사차식 적분과 넓이 비), 7번(극한 두 개로 계수 결정), 16번(조건 해석 뒤 F 결정과 적분)
