1. 5문항 예상 시간 합계: **14분**
2. 가장 어려운 문항 3개: **5번, 4번, 2번** 순서.
3. **문장은 짧은데 생각이 필요한 문항:** 4번. 불연속점을 통과하는 경우와 접하는 경우를 구별해야 한다. **계산이 길어서 오래 걸리는 문항:** 해당 없음. 상대적으로 3번이 넓이 계산을 요구하지만 계산 자체는 짧다. 5번의 소요 시간도 계산보다 근의 배치와 차수 판단에서 생긴다.

풀이 확인:

- **1번:** f(2)=-3. 항등식을 미분하면 4g(2)=f'(2)=-4이므로 g(2)=-1이다. 따라서 h'(2)=4-3g'(2)=1에서 g'(2)=1이다.
- **2번:** a가 0, 2가 아니면 연속 조건은 f(a)=0이므로 a=-1, 5이다. a=0에서는 좌우 극한이 다르다. a=2에서는 좌극한·우극한·함숫값이 모두 12이다. 따라서 합은 -1+5+2=6이다.
- **3번:** a≥3이면 곡선 아래 넓이는 9/a≤3이므로 이등분할 수 없다. a<3에서 윗변과의 교점의 x좌표를 s라 하면 s²=3a이다. 곡선 아래 정사각형 내부의 넓이는 s³/(3a)+3(3-s)=9-2s이다. 따라서 s=9/4, a=27/16이므로 16a=27이다.
- **4번:** g의 최솟값을 m이라 하면, 극한이 존재하지 않는 점이 정확히 두 개가 되는 조건은 0≤m<1이다. 이 두 점은 g(x)=1의 두 근이므로 근의 곱이 0이면 g(0)=1이다. g(x)=x²+bx+1로 놓으면 0≤1-b²/4<1, 즉 0<|b|≤2이다. 따라서 g(3)=10+3b의 최솟값은 b=-2일 때 4이다.
- **5번:** 불연속점은 f(x²)=0인 점이다. 서로 다른 불연속점이 세 개이므로 f의 서로 다른 음이 아닌 실근은 0과 양수 r 하나이다. x=0에서는 분모의 영점 차수가 분자의 두 배여서 유한한 극한이 존재하지 않는다. 따라서 ±√r에서는 극한이 존재해야 하므로 두 수 모두 f의 근이어야 한다. 만약 r=9이면 +3에서도 약분이 필요하고 -3에서는 분자의 영점 차수가 분모보다 커야 하므로 사차식으로는 불가능하다. 따라서 f(9)≠0이고 조건 (다)에서 f(-3)=0이다. 이제 0, r, √r, -√r, -3이 모두 근이므로 사차식이 되려면 r=√r 또는 -√r=-3이어야 한다. 후자는 제외했으므로 r=1이다. 따라서 f(x)=x(x-1)(x+1)(x+3)이고 f(2)=30이다.
