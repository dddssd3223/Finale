+주어진 문제와 그림만으로 손풀이했다. 예상 시간은 풀이와 답 확인을 포함한 상위권 학생 기준의 추정이다.

+## Q1
+
+1. **최종 답: ③, \(-1\)**
+
+2. **풀이 요지**
+   - 수평선 \(y=t\)와 그래프의 교점 수는 \(t\le-1\)에서 1개, \(-1<t\le0\)에서 2개, \(0<t\le1\)에서 3개, \(1<t\le2\)에서 2개, \(t>2\)에서 1개이다.
+   - \(u^2+au+b=0\)의 서로 다른 두 근을 \(r,s\)라 하면, 실근 5개를 얻으려면 \(0<r\le1\), \(s\in(-1,0]\cup(1,2]\)여야 한다.
+   - \(f(0)=1, f(1)=2\)이므로 (나)는 \(5+3a+2b=0\), 즉 \(2rs-3r-3s+5=0\)이다.
+   - 따라서 \(s=(5-3r)/(3-2r)\)이고, \(0<r\le1\)에서 \(5/3<s\le2\)이다.
+   - \(a+b=rs-r-s=(r+s-5)/2\le-1\)이며, \(r=1,s=2\)에서 등호가 성립한다.
+   - 이때 \(a=-3,b=2\)이고 두 높이의 교점 수가 각각 3개, 2개이므로 실제로 조건을 만족한다.
+
+3. **헤맨 곳·수정한 생각:** 교점 수를 세는 구간의 끝점 처리에 주의를 썼다. 특히 높이 0과 높이 1을 같은 구간으로 묶으면 안 된다. 별도의 계산 오류를 고치지는 않았다.
+
+4. **알아챈 함정:** 그림의 빈 점을 교점으로 세면 안 된다. 높이 1의 교점은 3개이고 높이 2의 교점은 2개라서, 경계에서 최댓값이 실제로 달성된다.
+
+5. **예상 시간·체감 난도:** 5분, **4/10**.

+6. **어색함·모호함·군더더기:** 통상적인 그래프 해석 아래 특별한 문제는 없다. 두 조건 모두 필요하다. 다만 교점 수 분류를 끝내면 이후 판단과 계산은 비교적 짧다.

+## Q2
+
+1. **최종 답: ①, \(4\)**
+
+2. **풀이 요지**
+   - \(g(x)=(x-h)^2+m\)이라 두면, 합성함수의 양쪽 극한이 달라지는 곳은 \(g(x)\)가 0 또는 1을 가로지르는 점이다.
+   - 꼭짓점에서 해당 높이에 접할 때에는 양쪽에서 같은 방향으로 접근하므로 극한은 존재한다.
+   - 따라서 극한이 존재하지 않는 점의 수는 \(m<0\)이면 4개, \(0\le m<1\)이면 2개, \(m\ge1\)이면 0개이다.
+   - 조건에 따라 \(0\le m<1\)이고, \(\alpha,\beta\)는 \(g(x)=1\)의 서로 다른 두 근이다. 그 곱이 0이므로 \(g(x)=x^2+px+1\)이다.
+   - \(0\le1-p^2/4<1\)에서 \(0<|p|\le2\)이므로 \(g(3)=10+3p\ge4\)이다.
+   - \(p=-2\), 즉 \(g(x)=(x-1)^2\)일 때 극한이 존재하지 않는 점은 0과 2뿐이므로 최솟값 4를 얻는다.
+
+3. **헤맨 곳·수정한 생각:** 꼭짓점이 높이 0 또는 1에 놓이는 경우를 별도로 확인했다. 불연속점의 원상 개수를 그대로 세지 않고, 실제로 그 높이를 가로지르는지 판단해야 했다.

+4. **알아챈 함정:** 바깥 함수가 불연속이라는 이유만으로 합성함수의 극한까지 존재하지 않는 것은 아니다. 특히 최솟값을 얻는 \(g(x)=(x-1)^2\)에서 \(x=1\)은 추가로 세지 않는다.

+5. **예상 시간·체감 난도:** 6분, **5/10**.

+6. **어색함·모호함·군더더기:** 수학적 모호함이나 불필요한 조건은 없다. 다만 ‘실수 \(t\)의 값은 \(\alpha\)와 \(\beta\)뿐’은 ‘실수 \(t\)는 \(\alpha,\beta\)뿐’으로 줄여도 뜻이 같다.

+## Q3
+
+1. **최종 답: ①, \(2\)**
+
+2. **풀이 요지**
+   - \(g'(x)=3x(x-2)\)이므로 극댓값은 \(g(0)=k\), 극솟값은 \(g(2)=k-4\)이다. 불연속 후보는 \(g(x)=0,1\)의 해이다.
+   - 두 높이 모두 바깥 함수의 값이 오른쪽 극한값과 같다. 따라서 가로지르는 점과 극대에서 접하는 점은 불연속이고, 극소에서 접하는 점은 연속이다.
+   - 높이 \(c\in\{0,1\}\)가 만드는 불연속점 수는 \(k<c\)일 때 1개, \(k=c\)일 때 2개, \(c<k<c+4\)일 때 3개, \(k\ge c+4\)일 때 1개이다.
+   - 두 높이의 개수를 합하면 (가)는 \(k\in(0,1)\cup[4,5)\)와 같다. (나)에서 \(g(-1)=k-4\in\{0,1\}\)이므로 \(k=4\) 또는 5이고, 결국 \(k=4\)이다.
+   - \(g(x)=(x+1)(x-2)^2=0\)의 해 중 \(-1\)만 불연속점이고, \(2\)에서는 연속이다.
+   - \(g(x)=1\), 즉 \(x^3-3x^2+3=0\)은 서로 다른 세 실근을 가지며 그 합은 3이다. 따라서 구하는 합은 \(-1+3=2\)이다.
+
+3. **헤맨 곳·수정한 생각:** \(g(x)=0,1\)의 서로 다른 해를 전부 세는 방식으로 바로 진행할 수 없어서 극대·극소에서의 접촉을 먼저 정리했다. 특히 \(k=4\)일 때 \(x=2\)를 제외하는 판단을 확인했다.
+
+4. **알아챈 함정:** 접하는 점이라고 모두 연속인 것은 아니다. 극대에서 아래쪽으로 접하면 극한값과 함수값이 달라 불연속이다. 또한 \(k=5\)도 \(x=-1\)에서 불연속이지만, 전체 불연속점은 2개라서 (가)에 어긋난다.
+
+5. **예상 시간·체감 난도:** 8분, **6/10**.

+6. **어색함·모호함·군더더기:** 특별한 모호함이나 불필요한 조건은 없다. (나)로 \(k=4,5\)를 먼저 얻은 뒤 두 경우만 확인하면 풀이를 더 짧게 만들 수 있다. 따라서 전체 매개변수 분류를 요구하는 문제보다는 실제 부담이 낮다.
