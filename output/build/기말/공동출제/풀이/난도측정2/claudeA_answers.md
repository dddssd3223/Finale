# solverA 풀이 보고

## 그림 판독 (공통)
- x<0: 감소하는 곡선. (-3,0)을 지나고, x→0- 일 때 -1로 간다((0,-1)은 빈 점). x→-∞일 때 위로 계속 올라간다고 읽었다. 그래서 치역은 (-1,∞)이다.
- 0≤x<1: f(0)=1(채운 점)에서 감소해 x→1- 일 때 0으로 간다((1,0)은 빈 점). 치역은 (0,1]이다.
- x≥1: f(1)=2(채운 점)인 직선 f(x)=-x+3. 치역은 (-∞,2]이다.
- 불연속점은 두 곳이다.
  - x=0: 좌극한 -1, 우극한 1 = f(0)
  - x=1: 좌극한 0, 우극한 2 = f(1)

## Q1
1. **최종 답: ③ -1**
2. **풀이 요지**
   - h(t)=t²+at+b로 두면 g=h(f(x))이다.
   - f(x)=t의 실근 개수 N(t)는 다음과 같다.

     | t의 범위 | N(t) |
     |---|---|
     | t>2 | 1 |
     | t=2 | 2 |
     | 1<t<2 | 2 |
     | 0<t≤1 | 3 |
     | t=0 | 2 |
     | -1<t<0 | 2 |
     | t≤-1 | 1 |

   - 실근이 5개이려면 3+2 조합뿐이다. 따라서 h의 두 근은 t₁∈(0,1], t₂∈(-1,0]∪(1,2]이다.
   - (나)에서 f(0)=1, f(1)=2이므로 h(1)+h(2)=0, 즉 3a+2b=-5이다.
   - a=-(t₁+t₂), b=t₁t₂를 대입하면 (2t₁-3)(2t₂-3)=-1이다. 또 a+b=(s-5)/2이다(s=t₁+t₂).
   - u=2t₁-3∈(-3,-1]로 두면 v=-1/u∈(1/3,1]이다. 따라서 t₂∈(5/3,2]이고, 이는 (1,2]에 들어가므로 적합하다. t₂가 (-1,0]에 있는 경우는 부호가 맞지 않아 불가능하다.
   - s=(u-1/u+6)/2는 u에 대해 증가한다. 최대는 u=-1일 때로, t₁=1, t₂=2, s=3이다.
   - 따라서 a=-3, b=2이고 a+b=-1이다.
3. **헤맨 곳**
   - 처음에는 a+b를 a, b의 1차식 조건만으로 최대화하려 했다. 근의 위치 제약을 반드시 써야 한다는 것을 알고 근 기준으로 바꿨다.
   - N(2)=2인지(x<0 가지가 2를 넘는지) 한 번 더 확인했다.
4. **알아챈 함정**
   - t=1과 t=0의 경계값 처리: N(1)=3, N(0)=2이다. 빈 점 (1,0) 때문에 t=0은 0≤x<1 구간에서 해가 없다.
   - 최댓값이 경계 t₁=1, t₂=2에서 실제로 달성되는지 확인해야 한다. 이때 g(0)=g(1)=0이 된다.
   - (2t₁-3)(2t₂-3)=-1로 묶는 인수분해를 떠올리는 것이 핵심이다.
5. **예상 시간 / 난도**: 9–11분, 6.5/10
6. **어색함·모호함**
   - x<0 가지가 2보다 커지는지(→∞)는 그림의 왼쪽 끝 모양으로 추정할 수밖에 없다. 그런데 N(2), N(t>2)가 이 판독에 달려 있다. 그림에서 왼쪽 가지가 y=2 위까지 보이게 하거나 "x→-∞일 때 f(x)→∞"라는 조건을 넣는 것이 안전하다.
   - 군더더기 조건은 없다.
7. **확신도**: 90%

## Q2
1. **최종 답: ① 4**
2. **풀이 요지**
   - g(x)=(x-p)²+q로 둔다.
   - x→t에서 극한이 존재하지 않는 것은 g(t)∈{0,1}이면서 g가 그 값을 가로지를 때뿐이다. 꼭짓점에서 최솟값으로 닿을 때는 우극한만 쓰므로 극한이 존재한다.
   - q에 따른 개수는 다음과 같다.

     | q의 범위 | 극한이 없는 t의 개수 |
     |---|---|
     | q<0 | 4개 |
     | 0≤q<1 | 2개 (g=1의 두 근) |
     | q≥1 | 0개 |

   - 따라서 0≤q<1이고, α·β=0에서 g(0)=1, 즉 p²+q=1이다. 이로부터 0<p²≤1이다.
   - g(3)=9-6p+p²+q=10-6p이다. 최소는 p=1, q=0일 때로 g(x)=(x-1)²이고 g(3)=4이다.
   - 확인: x=1에서 g→0+이므로 f→1이 되어 극한이 존재한다. 극한이 없는 t는 0과 2뿐이다.
3. **헤맨 곳**: q=0(꼭짓점 값이 0)을 처음에 "x=1에서도 극한이 없다"로 잘못 세려다가 고쳤다. 꼭짓점에서는 g→0+이므로 극한이 존재한다.
4. **알아챈 함정**
   - 극한의 존재와 연속을 혼동하기 쉽다(함숫값은 무관하다).
   - 꼭짓점에서 닿는 경우는 한쪽 극한만 쓰인다.
   - q=0을 포함해야 최솟값이 달성된다. 빼면 최솟값이 없다.
5. **예상 시간 / 난도**: 6–8분, 5/10
6. **어색함·모호함**
   - "α와 β뿐"이 α≠β를 뜻하는 것은 자연스럽다.
   - αβ=0은 "하나가 0"이라는 정보일 뿐이라 조금 노골적이지만 문제는 없다.
   - f(0), f(1)의 함숫값(채운 점)은 이 문항에서 쓰이지 않는다. 그림을 공유하므로 감수할 만하다.
7. **확신도**: 93%

## Q3
1. **최종 답: ① 2**
2. **풀이 요지**
   - g'=3x(x-2)이다. 극댓값은 g(0)=k, 극솟값은 g(2)=k-4이다.
   - f∘g는 g(x)∈{0,1}인 x에서 불연속이다. 예외는 극소점에서 그 값에 닿는 경우다. 이때는 g→c+이므로 우극한이 함숫값과 같아 연속이다. 반대로 극대점에서 닿으면 g→c-이므로 불연속이다.
   - (나)에서 g(-1)=k-4∈{0,1}이므로 k=4 또는 5이다.
   - 핵심 관찰은 g(x)-(k-4)=(x+1)(x-2)²이다.
   - k=4일 때:
     - g=0의 근은 x=-1(불연속)과 x=2(극소에서 0에 닿으므로 연속)이다.
     - g=1, 즉 x³-3x²+3=0은 서로 다른 세 실근을 가진다(모두 불연속).
     - 합계 4개로 (가)를 만족한다.
   - k=5일 때:
     - g=1의 근은 x=-1과 x=2(극소이므로 연속)이다.
     - g=0의 근은 1개뿐이다.
     - 합계 2개로 부적합하다.
   - 따라서 k=4이다. 불연속점의 합은 -1+(세 근의 합 3)=2이다.
3. **헤맨 곳**: x=2를 처음에 불연속으로 세면 k=4일 때 5개, k=5일 때 3개가 되어 답이 나오지 않았다. 다시 극소점의 연속성을 확인해 고쳤다.
4. **알아챈 함정**
   - 극소에서 닿는 점(x=2)은 연속이다.
   - 극대에서 닿는 점은 불연속이다(이 문항에서는 해당하지 않는다).
   - 세 근을 구하지 않고 근과 계수의 관계로 합을 처리한다.
5. **예상 시간 / 난도**: 7–9분, 5.5/10
6. **어색함·모호함**
   - "불연속인 x의 개수는 4"와 "x=-1에서 불연속"은 모두 필요하므로 군더더기가 없다.
   - 함정에 빠진 학생은 '해 없음'에 부딪혀 자기 오류를 되짚게 된다. 변별에는 오히려 좋다.
7. **확신도**: 95%
