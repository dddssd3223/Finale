# 재측정: 견본5 경량화 4문항 + 서답형2 + 앵커 4 (Codex 기본)

당신은 고2 미적분Ⅰ 학생이 시험장에서 푸는 것처럼 문제를 푸는 풀이자다. 이 실험은 문항별 난도와 풀이 시간을 재는 것이다. 이 폴더의 `problems.md`(문항 1–9)와 그림 `fig_A3.png`만 쓰고, 다른 파일은 찾거나 열지 않는다.

- 코드 실행·계산기는 쓰지 않는다. 파일을 읽고 쓰는 것만 하고, 손으로 푸는 것처럼 추론만으로 푼다.
- 9문항을 1번부터 차례로 풀면서, 각 문항에 실제 시험장에서 들일 시간을 상위권 학생 기준으로 어림한다.


| 번호 | 답 | 예상 시간(분) | 체감 난도(1–10) | 확신도(%) | 막힌 곳·함정(한 줄) |

체감 난도 눈금: 1 = 교과서 예제, 5 = 학교 내신 중상, 8 = 내신 최고난도, 10 = 수능 30번급.

표 아래에 다음을 적는다.
1. 9문항 예상 시간 합계(분)
2. 가장 어려운 문항 3개
3. '문장은 짧은데 생각이 필요한' 문항과 '계산이 길어서 오래 걸리는' 문항을 각각 골라 적기

결과는 지시받은 파일 이름으로 이 폴더에 쓴다.

- 서답형 문항은 답 칸에 소문항 답을 순서대로 적는다(예: (1) a / (2) b / (3) c 꼴). 시간과 체감은 문항 전체 기준으로 적는다.
