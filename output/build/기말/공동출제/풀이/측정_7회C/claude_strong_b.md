## 풀이 요지

1. 평균변화율 (28-7)/3=7, f'(c)=2c=7.
2. f(2)=-3. 미분: 2x g+(x²-4)g'=f' → 4g(2)=-4, g(2)=-1. h'(2)=f'(2)g(2)+f(2)g'(2)=4-3g'(2)=1.
3. f(t)=5t³+25t²+ct+d, f'(2)=60+100+c=70 → c=-90, f(2)=0 → d=40, f(1)=-20.
4. f(x-a)는 x=a에서 좌극한·함숫값 2, 우극한 4. f가 a에서 연속이면 f(a)=0 → a=-1, 5. a=0은 4≠16 불가, a=2는 12=12 가능. 합 6.
5. h(x)=f(x)+f(x+1)+x, h(0)=f(0)-1<0, h(1)=1>0.
6. f=x³+ax²+bx, A의 x좌표 -a=2, f'(2)=4+b=-b → b=-2, A(2,-4), OA²=20.
7. g=(x-p)²+q. 극한 부존재는 g가 0 또는 1을 '가로지르는' 점. 정확히 2개 ⇔ 0≤q<1 (g=1인 두 점). 한 점이 0 → p²+q=1, g(3)=10-6p, 0<p≤1에서 최솟값 4 (g=(x-1)²).
8. 0에서 T까지 P 이동거리 T²/2+6T=80 → T=8. b+a²/12=75, 8a+b=192 → a=18, b=48 (a=78은 b<0 불가). 양근 2개인 경우는 근 차 10, 중점 2 → 음근이라 모순. ∫0~8 = 448, ∫8~9 = -16, 거리 464.
9. 위 표 참조. g=(x+3)/(x(x²+1)(x²+3)), f(2)=2·1·3·5=30.
