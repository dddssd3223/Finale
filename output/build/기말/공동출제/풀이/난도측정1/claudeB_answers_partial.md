# solverB 풀이 결과 (고2 미적분Ⅰ 상위권 시점, 손풀이)

## P1 — 답 ④ (-16)
1. 최종 답: ④ f(0) = -16
2. 풀이 요지
   - |g-k|가 미분가능 ⇔ g=k인 모든 점에서 g가 미분가능하고 g'=0. g는 x→±∞에서 ±∞이므로 모든 k가 g=k의 해를 가진다.
   - f의 x^2항이 없으므로 근의 합 0. (나)에서 g=0의 서로 다른 실근이 2개 → f는 (이중근 r, 단근 -2r)이고 c는 둘 중 하나이거나, f의 실근이 1개이고 c가 그것과 다른 경우로 나뉜다.
   - c=r(이중근)이면 x=-2r에서 g=0이면서 꺾임이 생겨 k=0 탈락, 다른 k는 양 끝 가지에서 g'≠0인 점을 지나므로 S가 공집합. 실근 1개인 경우도 같은 이유로 대체로 탈락(아래 헤맨 곳 참고).
   - c=-2r(단근)이면 g=(x+2r)|x+2r|(x-r)^2 는 C^1이고 g=0의 두 근에서 g'=0이므로 0∈S, 다른 k는 극점이 아닌 점을 지나므로 S={0}. (가) 성립.
   - (다) 극솟값 -81: r>0이면 극솟값이 0뿐이라 불가. r<0이면 x=-r/2에서 극솟값 -81r^4/16=-81 → r=-2.
   - f=(x+2)^2(x-4)=x^3-12x-16, f(0)=-16.
3. 헤맨 곳: 처음에 "k=0이 S의 원소가 되려면 g가 x=c, 근에서 모두 미분가능" 이라는 판정을 정리하는 데 시간을 썼다. c가 f의 단근일 때 (x-c)|x-c|가 미분가능하다는 점을 처음엔 놓칠 뻔했다. 실근 1개인 경우(S가 0이 아닌 k 하나로 존재하는 경우, g'=0과 g''=0이 동시에 되는 변곡점 상황)는 엄밀히 닫지 못하고 "조건이 너무 많이 맞아야 하므로 아니다"로 넘어갔다. 시험장이면 여기서 확신이 떨어진다.
4. 함정: (i) |g-k|의 미분가능성을 "g=k에서 g'=0" 조건으로 번역해야 함. (ii) c가 f의 단근이면 절댓값과 인수가 겹쳐 꺾임이 사라짐. (iii) r의 부호에 따라 극솟값 위치가 달라짐(r>0이면 -81 불가). (iv) (가)가 c=r 경우와 실근 1개 경우를 배제하는 핵심.
5. 예상 풀이 시간 12~15분(상위권도 경우 나누기에서 지연), 체감 난도 7.5
6. 어색함: S 정의에 "실수 c"인데 "두 상수 a, b"와 구분해서 쓴 점은 어색(c도 상수). (가)가 사실상 핵심이고 (나)(다)는 경우 좁히기. (가) 없이 (나)(다)만으로는 c=r 경우 등이 남아 답이 불확정일 것 같다. 반대로 (나)는 (가)와 (다)가 있으면 상당 부분 중복(실근 1개 경우는 (나)가 아니라 (가)로 배제하는 게 자연스러움). 군더더기보다는 "경우의 수가 많아 엄밀한 배제가 어려운 것"이 문제.
7. 확신도 80%

## P2 — 답 ① (4)
1. 최종 답: ① 4
2. 풀이 요지
   - f의 불연속은 u=0(좌극한 -1, 우극한 1)과 u=1(좌극한 0, 우극한 2, f(1)=2).
   - g(t)가 0 또는 1이 아니면 f가 연속이라 극한 존재. g(t)=0 또는 1인 t에서, 꼭짓점이 아닌(단근) 점이면 양쪽에서 g가 그 값을 가로질러 극한 불일치 → 존재하지 않음. 꼭짓점(이중근)이면 g가 한쪽에서만 접근해 극한 존재(0⁺ → 1, 1⁺ → 2).
   - 꼭짓점 (v, m)이라 하면 m<0이면 DNE 4개(탈락), m=1이면 0개(탈락), m>1이면 0개.
   - m=0: g=1의 두 단근 v±1만 DNE, 곱 v²-1=0 → v=±1. g=(x-1)^2이면 g(3)=4, g=(x+1)^2이면 16.
   - 0<m<1: g=1의 근 v±√(1-m), 곱 0 → m=1-v², g(3)=10-6v, v∈(-1,1), v≠0 이므로 4보다 크다(v=1은 m=0 경우로 넘어감).
   - 최솟값 4 (v=1에서 달성).
3. 헤맨 곳: 처음에 m=0일 때 g=0이 이중근인데 f(g(x))의 극한이 존재하는지(0⁺로만 접근 → 1) 확인하느라 그림의 (0,1) 채운 점·(0,-1) 빈 점을 다시 봤다. 0<m<1 경우에서 아래로 열린 구간이라 최솟값이 안 잡히는 것 같다가 m=0 경우가 끝점을 달성함을 알았다.
4. 함정: 꼭짓점에서 접하는 경우(합성함수 극한이 존재) 구분, 극한은 함숫값 무관, 최솟값이 열린구간 하한이 아니라 m=0 경우에서 나옴, m<0일 때 DNE가 4개라 탈락.
5. 예상 풀이 시간 6~8분, 체감 난도 4.5
6. 어색함: 군더더기 거의 없음. "αβ=0"이 v=±1을 고르는 유일한 단서. 다만 선지 ①이 답이라 정답이 가장 작은 선지이고, 그림 읽기+경우 분류가 끝나면 계산이 단순해서 18번(최고난도)로는 가볍다.
7. 확신도 88%

## P3 — 답 ③ (8)
1. 최종 답: ③ 8
2. 풀이 요지
   - f가 증가함수이면 f와 f^{-1}의 교점은 y=x 위에만 있다. f(x)=x → x=0, x²=(1-b)/a. 3개가 되려면 a>0, 0≤b<1.
   - (나): ∫_{-2}^0 f = -(4a+2b)=1/2 → b=-1/4-2a. 그런데 a>0이면 b<0이 되어 증가함수 조건(b≥0)과 모순. 따라서 증가 경우 불가능.
   - 감소함수(a<0, b≤0)이면 교점은 y=x 위의 원점과, y=-x 위의 (±x0, ∓x0) (x0²=(b+1)/(-a), b>-1) → 정확히 3개. 이때 b=-1/4-2a≤0 → -1/8≤a<0.
   - 넓이: 두 곡선은 y=-x에 대칭. 한 쪽 반(f와 y=-x 사이) = ∫_0^{x0}(f+x)dx=(b+1)x0²/4. 전체는 4배 → (b+1)x0² = (1+b)²/(-a).
   - t=-a∈(0,1/8]: A=(3/4+2t)²/t = 9/(16t)+3+4t, 이 구간에서 감소 → t=1/8에서 최소 8 (f=-x³/8).
3. 헤맨 곳: 처음에 "역함수 있음 → 증가"로 단정하고 a>0,0≤b<1로 풀다가 (나)와 모순이 나서 감소 경우로 돌아갔다. 넓이의 배수를 셀 때 로브 2개 × 각 로브 = 반쪽 2개를 헷갈려 한 번 다시 셌다. 최솟값이 극값(t=3/8)이 아니라 범위 끝(t=1/8)이어서 처음에 이상했다.
4. 함정: 역함수가 존재하면 증가라고 착각(감소도 가능), 감소일 때 교점이 y=x 밖(y=-x 위)에도 생김, a 범위가 b≤0 조건에서 나옴, 최소가 끝점에서 달성.
5. 예상 풀이 시간 12~14분, 체감 난도 7
6. 어색함: "역함수가 존재한다"가 사실상 단조성만 주고 증가/감소 판단은 학생 몫이라 의도된 함정으로 보인다. (가)(나) 모두 필요(둘 다 없으면 안 풀림). "서로 다른 점의 개수는 3"에서 증가 경우를 (가)가 아니라 (나)가 배제하는 점이 약간 의외(학생이 (가)만 읽고 증가로 풀면 (나)와 충돌). 군더더기 조건은 없다.
7. 확신도 85%

## P4 — 답 ④ (30)
1. 최종 답: ④ 30
2. 풀이 요지
   - g가 불연속인 점 = f(x²)=0인 x(분모 0이면 제거가능이어도 정의 안 되므로 불연속). f의 양의 근 r마다 x=±√r 두 점, 근 0이면 x=0 한 점, 음의 근은 실수 x 없음.
   - 불연속점이 3개 → f는 근 0과 양의 근 하나 r를 갖는다.
   - 0에서는 분자 차수 m0, 분모 차수 2m0라 g~x^{-m0}로 발산 → 극한 존재하지 않음. (나)에서 p가 하나이므로 이 p=0이 유일. 따라서 x=±√r에서는 극한이 존재해야 → ±√r이 모두 f의 근. √r이 양의 근이니 √r=r → r=1. 근은 0, 1, -1.
   - 사차이므로 근 하나 더. (다): -3이 불연속점이 되려면 r=9로 모순 → 불연속 아님, g(-3)=0 → f(-3)=0. 따라서 f=x(x-1)(x+1)(x+3).
   - 검산: g=(x+3)/(x(x²+1)(x²+3)) (x≠0,±1), x=±1에서 극한 존재, 0에서 발산. 조건 모두 성립.
   - f(2)=2·1·3·5=30.
3. 헤맨 곳: "불연속"에 분모 0인 제거가능 점이 포함되는지 잠깐 확인했다(정의 안 되면 불연속). 0에서 극한이 ∞로 발산하는 것을 "극한 존재 안 함"으로 보는지(고교 과정에서 발산=존재하지 않음) 확인. 사차 조건에서 남은 한 근 처리를 (다)로 알아챘다.
4. 함정: 양의 근 하나가 불연속점 2개를 만든다는 점, √r이 근이 되면 또 다른 불연속점이 생기므로 r=1로 고정, 0에서의 발산, (다)가 -3을 불연속이 아닌 점으로 보고 근으로 지정, x=0의 중복도가 2 이상이면 (다) 실패.
5. 예상 풀이 시간 8~10분, 체감 난도 6
6. 어색함: "서로 다른 세 실수 a,b,c"와 (나)의 "p 한 개"가 정보가 겹친다. (다)는 x=-3에서 f(9)=0을 쓸지 f(-3)=0을 쓸지 갈리는데 후자임을 r=1 결정 후에야 알 수 있어 순서가 자연스럽다. 발산(∞)을 "극한값이 존재하지 않는다"로 본다는 전제가 필요(교육과정상 맞지만 학생이 헷갈릴 수 있음). 군더더기는 크지 않으나 (가)(나) 중 (나)가 r=1을 정하는 핵심.
7. 확신도 87%
