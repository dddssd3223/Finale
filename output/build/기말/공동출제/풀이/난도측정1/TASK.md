# 블라인드 풀이 실험 (난도 측정 1)

당신은 고2 미적분Ⅰ 상위권 학생이 시험장에서 푸는 것처럼 문제를 푸는 풀이자다. 이 폴더의 `problems.md`(P1–P4)와 그림 `fig_P2.png`만 쓴다. 다른 파일을 찾거나 열지 않는다.

- 코드 실행·계산기를 쓰지 않는다(셸 명령 금지, 파일 읽기·쓰기만). 손으로 푸는 것처럼 추론만으로 푼다.
- 한 문항에 쓸 수 있는 '시험장 시간'은 15분이라고 가정한다.

문항마다 아래를 쓴다.
1. 최종 답 번호와 값
2. 풀이 요지(3–8줄)
3. 헤맨 곳, 처음에 틀리게 생각했다가 고친 곳
4. 알아챈 함정
5. 상위권 학생 기준 예상 시간(분)과 체감 난도(1–10, 10=수능 30번급)
6. 어색함·모호함·군더더기 조건(없어도 답이 같을 것 같은 조건)
7. 확신도(%)

마지막에 네 문항을 어려운 순서로 줄 세우고, '학교 내신 18번(최고난도)으로 적당한가'를 문항별로 한 줄씩 쓴다. 결과는 이 폴더의 `codex_answers.md`에 쓴다.
