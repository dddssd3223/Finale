## P1. L42 → 학교 17

원문은 몫의 극한 "lim g(x)/f(x)"의 존재 조건으로 삼차 g를 정한다. 변형은 같은 그래프에 "lim (f∘g)(x)의 값이 존재하지 않는 t는 α와 β뿐"이라는 조건을 걸고, 이차 g에 대해 g(3)의 최솟값을 묻는다.

| 원문 단계 | 판정 | 변형에서 |
|---|---|---|
| x=0, x=1의 점프값(−1|1, 0|2) 읽기 | 그대로 | 같은 값을 u=g(x)의 도착값으로 씀 |
| 나머지 점에서 f 연속·0 아님 | 변형 | 연속만 필요 |
| x=0에서 좌우극한 ∓g(0) → g(0)=0 | 삭제 | — |
| x=1에서 0/0 → (x−1)² 인수 | 삭제 | — |
| g 결정, g(3)=12 | 변형 | g의 족을 구한 뒤 최솟값 4 |
| (신규) 합성극한 원리: 꼭짓점에서는 한쪽에서만 접근 | | |
| (신규) 최솟값 k로 다섯 경우 분류 | | |
| (신규) 경우별 극한이 없는 t 개수 세기 | | |
| (신규) αβ=0 → g=(x∓1)², x²−rx+1 | | |

- 요소: f 그래프만 유지했다. f 식, 범위, 단서는 삭제했고, 조건과 형식은 교체했다. g의 차수와 질문은 변형했다.
- 함수 교체: g를 삼차에서 이차로 바꿨고, 결합 방식을 g/f에서 f∘g로 바꿨다.
- 품질: 모든 조건이 일한다. 함정(꼭짓점의 한쪽 극한, 0<k<1에서 하한 4가 달성되지 않음)은 공정하다. 문장도 자연스럽다.

- 요소: 형식만 유지했다. 함수 꼴은 일반 함수에서 삼차로 교체했고, f(3)=−3은 삭제했다. 기함수·단조·교점·적분 조건과 질문은 변형했다.

## 결론

**축은 같다.** 17번은 두 쪽 모두 설정을 유지하고 원리를 교체했다. 18번은 두 쪽 모두 원리를 유지하고 설정을 교체했다. 함수 교체도 양쪽 모두 있다.

**거리는 다르다.** 견본3 17·18은 학교 문항보다 원문에 가깝다.

| | 학교 17 / 18 | 견본3 17 / 18 |
|---|---|---|
| d_step | 0.78 / 0.83 (평균 0.81) | 0.63 / 0.70 (평균 0.66) |
| 원문 단계 유지율 r_step | 0.40 / 0.30 | 0.60 / 0.43 |
| 요소 유지율 r_elem | 0.25 / 0.44 | 0.44 / 0.63 |

- 견본3 17은 원문의 핵심 두 단계(y=−x 대칭, 넓이 4배)를 그대로 쓴다. 학교 17은 그래프 읽기만 남기고 판정을 모두 바꿨다.
- 견본3 18은 S 정의 문장과 판정 원리를 글자 그대로 남겼다. 학교 18은 "분모의 영점 세기"와 "분자 근 맞추기"를 변형해서만 남겼다.
- 서답형2(0.86)는 오히려 학교 문항보다 멀다. 다섯 쌍 중 "둘 다 교체"에 가장 가깝다.

학교 수준의 거리(약 0.8)에 맞추려면 견본3 17·18에서 원문 단계를 하나씩 더 바꿔야 한다. 17번이면 "4배 넓이" 대칭 단계, 18번이면 S 정의를 그대로 쓰는 부분이 후보다.

**품질은 대체로 같고, 두 곳이 다르다.**
1. 견본3 17번 (가)는 논리상 잉여다. 학교 17·18번은 모든 조건이 일한다. (가)를 실제로 일하는 조건으로 바꾸거나 빼야 한다.
2. 무게가 다르다. 학교 17·18번은 판단이 무겁고 계산이 가볍다. 견본3 17번은 계산이 약간 우세하고, 견본3 18번은 판단 우세지만 시간이 8–10분으로 학교 18번(6–8분)보다 무겁다.

함정의 공정성과 문장의 자연스러움은 다섯 문항 모두 문제가 없다.
