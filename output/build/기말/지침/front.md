### 0-4. 17·18번과 서답형2는 구조 변경 필수
구조 변경 = 원본의 함수·그래프·설정 틀은 남기되, 미지수를 정하는 판정 원리(풀이 메커니즘)를 바꾸는 것. 원본 해설의 핵심 한 줄이 그대로 통하면 구조 변경이 아니다.
숫자·조건 변경 = 같은 판정 원리를 다른 수치·범위·부호로 한 번 더 돌리는 것.

| 구분 | 사례 | 판정 |
|---|---|---|
| 구조 변경 | 2학기 중간 17번(L42): 같은 조각 그래프 유지, "몫 g/f의 극한 존재(f의 근을 g가 상쇄)" → "합성 f∘g의 극한 존재(속함수가 불연속점에 어느 쪽에서 다가가는가)". 이차 g, 최솟값으로 질문 | 어려워짐, 1등급 변별 |
| 구조 변경 | 2학기 중간 18번(C30): 이차 → 사차, 함수 두 개 → f(x)/f(x²) 하나, 조건 셋 병합 → x=0에서 차수 비교라는 새 단계 | 어려워짐 |
| 구조 변경 | J1: 직선 부착 → f²+포물선 부착. S′=f²(1+2f′)이 되어 "접선일 때 최대"가 깨짐 / I70: 칸별 부호 선택 정의식을 f²·곱형·2^(−n) 감쇠로 교체 / 1회 17번 D72: 수평선 y=t → 원점 지나는 y=tx(극값 대신 원점 접선 기울기) | 어려워짐 |
| 조건 변경(부족) | 2학기 중간 16번(C54): 특이점 f(x)=0 → f(x)=1, 따로 정한 값 상수 → −\|x−2\|. 판정 원리 동일 | 같음 |
| 조건 변경(부족) | D72 학교 기출: 합 9 → 8·7, min(a+b) → min(ab) / I70 학교 기출: 최소 ↔ 최대 반전 / M32: 부호 조건 4 → 3·6·2 | 같음(원리 이해 학생에겐 동일 난도) |
