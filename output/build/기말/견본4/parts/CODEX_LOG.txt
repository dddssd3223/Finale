### 1–8번 공통: 앞번호는 짧고 무겁게 (2학기 중간 기준)
양정고 2학기 중간 1–8번은 문장이 짧은데 생각이 필요한 문항이다. 계산이 길어서 무거운 것이 아니다. 개념 판단 하나가 핵심이다.
- 사례:
  - 1번: 그래프로 좌극한 읽기
  - 4번: 도함수 범위로 \(f(3)\)의 최댓값·최솟값
  - 5번: 부등식으로 묶인 비의 극한
  - 6번: 단조·연속 함수의 사잇값 정리
  - 7번: 집합 조건 \(\{x\mid f(x)=2\}\)로 근 정하기
  - 8번: 항등식에서 곱의 미분
- 기준:
  - 문장은 2–3줄 이내, 수식 1–2개로 쓴다.
  - 풀이는 '개념 판단 1개 + 짧은 계산'이다(상위권 2–4분).
  - 계산 단계가 3개를 넘거나 같은 계산을 되풀이하면 앞번호로 쓰지 않는다.
- 판단 장치 예: 등호 포함 여부, 범위로 최댓값·최솟값 읽기, 조건 집합의 원소, 단조성, 좌·우극한 구분, 부호 판단, 그래프 읽기.
- 숫자만 바꾼 단순 계산 문항(예: 정적분 값 계산)은 1–2번 중 한 문항까지만 쓴다. 나머지 앞번호에는 판단 장치 하나를 넣는다.
- 측정: 블라인드 풀이 패널에서 1–8번의 체감 난도와 시간이 2학기 중간 같은 번호의 ±1 안이어야 한다(`공동출제/견본4_난도계획.md`).

### 4-3. 난도 지수
- idx = (상·최상 문항 배점 합) + 0.5 × (중상 문항 배점 합). 서답형은 고난도 소문항 배점(6점)만 넣는다.

- 24 미만이면 13–16번 중 하나를 상으로 올리고, 28 초과면 16번이나 서답형1을 한 단계 낮춘다. 상·최상은 17·18·서답형2와 16번 이내로 제한한다.

- 학교는 원문에서 멀리 바꾸되(구조 거리 0.8) 판단 위주로, 계산은 가볍게 냈고 상위권 체감은 5–6/10이었다. 견본3은 덜 바꾸고(0.63–0.70) 무겁게 내서 7–8/10이 됐다.
- 견본4 17 초안(M27): 흔한 패턴(t-개수함수)으로 직선 높이만 움직였고, 원문 원리 줄이 그대로 통했다. 출제자 자기 표시 '구조 변경'을 믿고 독립 검토(관문 3)를 건너뛴 것이 원인이었다.

## 0-7. 형식 (2학기 중간 20문항 원문 대조)
학교는 내용과 함께 문장 짜임도 손본다. 아래는 20문항 전부를 원문과 맞대어 뽑은 규칙이다. 괄호는 근거 문항 번호.

**선지**
- 5개 **등차 배열**(18/18): 공차 1 정수가 기본(9문항), 그 밖에 2·5·\(\frac12\)·\(\frac15\)·\(\frac1{20}\). 선지는 새로 만든다(원문 선지 재사용 1).
- 음수 답은 0에서 내려가는 배열(10번: \(0, -5, \cdots, -20\)), 큰 수부터 내려가는 배열도 있다(12번: \(10\)–\(6\)).
- 답이 분수면 질문에 상수배를 붙이거나 묻는 양을 바꿔 정수로 만든다(16번 \(10g(7)\), 15번 \(\overline{\mathrm{OA}}^2\)).
- 원문이 단답형이면 문장 틀은 두고 '~의 값은?' 5지선다로 바꾼다(단답 원문 8개 중 7개).
- 오답 근거(경우 누락·경계 제외 값)는 **등차 배열 안에 들어가도록** 공차·시작값을 고른다. 근거 값을 넣으려고 배열을 깨지 않는다.

**조건 상자와 질문 위치**
- 상자가 있으면 기본은 **질문 → [배점] → 상자**: '…가 다음 조건을 만족시킬 때, ~의 값은? [4.8점]' 뒤에 상자(4, 7, 13, 17). 상자 안 조건은 '모든 실수 \(x\)에 대하여 ~이다.' 같은 문장형.
- 상자 뒤 질문형('~가 다음 조건을 만족시킨다.' + 상자 + '~의 값은?')은 18번 1개뿐이고, 상자 뒤에는 질문 한 줄만 둔다(상자 뒤에 새 조건·정의를 두지 않는다).
- 고난도는 조건을 (가)(나)(다)로 늘리거나, 본문 조건을 라벨 없는 상자로 떼어 낸다. 부정 조건의 '존재하지 않는'에 밑줄(17, 18).

**함수 소개 순서**
- 조건 안에서 정의하던 보조함수는 **첫 문장으로 올리고**, 상자에는 성질만 남긴다(18번: \(g(x)=\dfrac{f(x)}{f(x^2)}\)를 본문으로). 조건에서만 쓰는 문자는 상자 안에서 '서로 다른 세 실수 \(a\), \(b\), \(c\)에 대하여'로 소개(18).
- 미정계수는 첫머리에서 먼저 소개('두 상수 \(a\), \(b\)에 대하여 함수 …'), 질문은 \(a+b\)처럼 합으로(2).
- 그림 문항은 '함수 \(y=f(x)\)의 그래프가 그림과 같다.'를 첫 문장으로 따로 두고, 그림 다음에 다른 함수를 소개해 질문(1, 17). 조각함수 식은 지우고 그림만 남길 수 있다(17).
- 풀이에 쓰는 수치(꼭짓점 좌표, 길이, 함숫값)는 본문에 쓴다. 그림에만 두지 않는다(그림은 모양 확인용). 견본4 14번 측정에서 좌표가 그림에만 있어 풀이자 1명이 풀지 못했다.
- 식으로 주던 함수를 말+그림으로 바꿀 수 있다: '최고차항의 계수가 \(1\)인 삼차함수 \(f(x)\)에 대하여 그림과 같이 곡선 \(y=f(x)\)가 원점 \(\mathrm O\)를 지난다.' 이때 그림 모양을 확정하는 단서를 단다(15).
- 자체 출제 선택형은 2문장: '좌표평면 위에 ~인 원 \(C_1\)과 ~인 원 \(C_2\)가 있다.' + '~를 \(f(t)\)라 할 때, ~의 값은? (단, …)'(14).

**단서·배점·수식**
- 단서 '(단, …)'는 변형으로 자명해지면 지우고(7, 17), 새 설정에는 위치 관계·좌표 부호·정수 조건 단서를 단다(15, 20).
- 배점은 질문 문장 끝, 단서 뒤. 상자가 뒤에 오면 상자 앞(20/20). 번호 순으로 4.0 → 5.2.
- 조각함수·부등식·관계식·극한 조건 묶음은 가운데 줄(9/20). 구하는 극한식, \(g(x)=f(x)/f(x^2)\) 같은 짧은 정의는 본문 수식. 서답형 머리말의 조각함수는 본문 줄 안.
- 작은 문구: '~이 ~와 같도록' → '~과 ~가 서로 같도록'(3), '점 \(\mathrm O(0, 0)\)' → '원점 \(\mathrm O\)'(15), 관계식은 인수 곱 꼴 \((x+2)(x-2)\)(8).

**서답형**
- '함수 ~에 대하여 다음 물음에 답하시오. (단, …)' 머리말 + (1)(2)(3). 서술형은 '~을 조사하시오'(연속성 → 미분가능성, 19), 답형은 중간값 → 최솟값 → 최댓값(20). 원문 조건 상자는 머리말 서술문으로 푼다(20). 소문항마다 '[n점, 풀이과정을 상세히 쓰시오.]' 또는 '[n점, 답만 적으시오.]'.

- 골격 지문 K: 숫자를 #로 바꾼 6글자 조각

- 금지(구조 변경 미달): 17·18·서답형2가 익스텐션·분석집 어느 문항과든 골격 0.60 이상

import sys, os, re, json, gzip, base64, zlib, array, importlib.util
HERE = os.path.dirname(os.path.abspath(__file__))
FP = os.path.join(HERE, 'ext_fp.json.gz')
N = 6

def norm(t):
    t = re.sub(r'!\[[^\]]*\]\([^)]*\)', '', t)
    t = re.sub(r'<[^>]+>', '', t)
    t = t.replace('&lt;', '<').replace('&gt;', '>').replace('&amp;', '&')
    t = re.sub(r'\\(?:left|right|displaystyle|textstyle|limits|quad|qquad|,|;|!| )', '', t)
    t = re.sub(r'\\[dt]?frac', 'frac', t)
    t = re.sub(r'\\(le|leq)q?\b', '≤', t); t = re.sub(r'\\(ge|geq)\b', '≥', t)
    t = re.sub(r'\\(?:\(|\)|\[|\])', '', t)
    t = re.sub(r'\\begin\{cases\}|\\end\{cases\}|&|\\\\\[?[0-9a-z]*\]?', ' ', t)
    t = re.sub(r'[{}\s$*]', '', t)
    t = re.sub(r'[①②③④⑤]', '|', t)
    return t

def shingles(s):
    return sorted({zlib.crc32(s[i:i + N].encode()) for i in range(max(1, len(s) - N + 1))})

def skel(s):
    return re.sub(r'\d+', '#', s)

def nums(t):
    b = norm(t).split('|')[0]
    return re.findall(r'\d+(?:\.\d+)?', b)

def pack(v):
    return base64.b64encode(array.array('I', v).tobytes()).decode()

def unpack(b):
    a = array.array('I'); a.frombytes(base64.b64decode(b)); return set(a)

def build(corpus, study=None):
    """corpus: 익스텐션 1,746문항(corpus.json), study: 양정고2 부교재 분석집(study.json, 원문 143 + 변형 290)"""
    C = json.load(open(corpus))
    out = []
    def add(i, key, hdr, text, src):
        r = norm(text)
        out.append(dict(id=i, key=key, hdr=hdr, src=src, R=pack(shingles(r)), K=pack(shingles(skel(r))), nums=nums(text)))
    for o in C:
        add(o['id'], o['key'], o['hdr'], o['problem'], 'EXT')
    if study:
        for s in json.load(open(study)):
            add(f"STUDY-{s['key']}-원문", s['key'], f"분석집 {s['key']} 원문", s['problem'], 'STUDY')
            for v in s['variants']:
                add(f"STUDY-{s['key']}-변형{v['no']}", s['key'], f"분석집 {s['key']} 변형{v['no']}", v['problem'], 'STUDY')
    with gzip.open(FP, 'wt', encoding='utf-8') as f:
        json.dump(out, f, ensure_ascii=False)
    print('지문', len(out), '(익스텐션', sum(d['src'] == 'EXT' for d in out), '· 분석집', sum(d['src'] == 'STUDY' for d in out), ') →', FP, os.path.getsize(FP) // 1024, 'KB')

def load():
    with gzip.open(FP, 'rt', encoding='utf-8') as f:
        D = json.load(f)
    for d in D:
        d['R'] = unpack(d['R']); d['K'] = unpack(d['K'])
    return D

def score(text, D, top=3):
    r = norm(text); R = set(shingles(r)); K = set(shingles(skel(r)))
    res = []
    for d in D:
        cr = len(R & d['R']) / max(1, min(len(R), len(d['R'])))
        ck = len(K & d['K']) / max(1, min(len(K), len(d['K'])))
        res.append((ck, cr, d, nums(text) == d['nums']))
    res.sort(key=lambda x: (-x[0], -x[1]))
    return res[:top]

HIGH = {17, 18, 'S2', '17', '18'}   # 구조 변경 필수 자리: 익스텐션·분석집 모두 골격 0.60 미만이어야 함

def verdict(ck, cr, same, no=None):
    if cr >= 0.95 or (ck >= 0.85 and same): return '금지(동일 문항)'
    if no in HIGH and ck >= 0.60: return '금지(구조 변경 미달)'
    if ck >= 0.85: return '허용(숫자만 다름)'
    if ck >= 0.60: return '주의(구조 유사)'
    return '통과'

def check(paths):
