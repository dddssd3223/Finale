## 작성 규칙 (사용자가 여러 번 지적한 것)
- **수식 표기**
  - 수식은 `\( \)`(KaTeX), 가운데 줄 수식은 `\[ \]`로 쓴다. HTML 안에서 `<`는 `&lt;`로 쓴다.
  - 조각함수·부등식·관계식은 가운데 줄로, 짧은 정의는 문장 안에 쓴다.
- **군더더기**: 쓸데없는 괄호 설명, 답이 바뀌지 않는 단서, '(자체 제작)' 같은 표기는 넣지 않는다.
- **말투**: 자료식 말투(0-6)를 쓴다. '속한다', '생각하자', '~마다', '중근' 같은 말은 쓰지 않는다.
- **선지**
  - 5개 등차 배열로 둔다. 기본은 공차 1이고 2, 5, 1/2 등도 쓸 수 있다.
  - 학교식: 오름차순 위주(내림차순은 회당 2개까지), 공차 1 위주(2·5·1/2·1/5 가능). 오답 근거를 넣으려고 공차를 키우지 않는다(0-8).
  - 원문이 단답형이면 5지선다로 바꾼다.
  - 13번 이상에서 답이 분수가 나오면 상수배를 붙이거나 묻는 양을 바꿔 정수로 만든다.
- **질문 위치**: 조건 상자가 있으면 '…가 다음 조건을 만족시킬 때, ~의 값은?' 다음에 상자를 둔다.
- **함수 소개 순서**: 함수·미정계수는 첫 문장에서 소개한다.
- **중복 금지**: 익스텐션·분석집과 같은 문항은 금지다. 숫자만 바꾼 출제는 1–16번에서는 허용되지만, 17·18·서답형2에서는 허용되지 않는다.
- **평가 요소 유지**: 어느 번호든 원문이 재는 단원 핵심 개념(극한·연속, 미분가능성, 넓이 등)은 바꾸지 않는다. 바꾸는 것은 설정·원리·수치이고 주제는 그대로 둔다.
- **출제 범위**: 미적분Ⅰ 다항함수만 쓴다. 넓이는 \(y=f(x)\) 그래프를 \(x\)로 적분해 구한다. \(x=g(y)\) 꼴 곡선, 이차곡선, \(y\)에 대한 적분, 지수·로그·삼각함수는 금지다(front.md 0-1-1).
- **17·18 문장 길이**: 원문 길이와 조건 수를 유지하거나 늘린다(학교 18번 270→272자, 조건 2→3). 앞번호 길이 규칙은 1–8번에만 쓴다. 계수를 미리 정해 조건을 줄이는 식으로 짧게 만들지 않는다.
- **그림 문항 수**: 한 회에 2–3개. 1–8번에는 두지 않고 9번 이후에 흩어 둔다. 그림은 새로 만들지 않고, 원문에 그림이 있는 문항을 분담 단계에서 골라 그 그림을 쓴다. 분담표에 그림 번호와 원문을 미리 정한다.
- **그림 그리기 (1회 지적 반영):** 그림은 Claude가 `지침/figkit.py`로 그린다(시험지 수식 글꼴 HyhwpEQ·Tinos, 화살표 축, 회색 칠). Codex 실행기에는 이 글꼴이 없어 DejaVu로 대체되어 스타일이 달라지므로, Codex는 그림 파일을 만들지 않고 본문에 `<div class="fig"><img src="fig_번호.svg" style="width:150pt"></div>` 자리와 그릴 내용(함수식·라벨·칠할 영역)만 note에 적는다. 그림 스크립트는 `<회차>/figs/fig번호.py`에 둔다.
- **줄 바꾼 식(\[ \]) (1회 지적 반영):** 원문에 줄을 바꿔 쓴 식이 있는 자리에만 쓴다. 원문에 없던 짧은 식(부등식 한 줄, 넓이 관계식, 조건 상자 안의 짧은 식)은 문장 안에 쓴다. 억지로 줄을 바꿔 들여쓰지 않는다. 조각함수(cases)처럼 여러 줄인 식만 예외다.
- **단서·조건 표현 (1회 16번 지적):** 원문의 단서("(단, \(n\)은 자연수이다.)" 등)와 조건 범위는 원문 표현 그대로 둔다. 풀이에 필요 없는 범위로 좁히거나(예: \(n=1,2,\ldots,6\)) 새 단서를 덧붙이지 않는다. 원문 단서가 줄을 바꿔 따로 있으면(`<br>(단, …)`) 그 배치도 따른다. 새 단서는 답이 정해지는 데 꼭 필요할 때만 쓰고 note에 이유를 적는다.
- **그림 수치**: 풀이에 쓰는 좌표·길이·값은 본문에 쓰고, 그림은 모양 확인용으로만 쓴다.
- **앞번호 길이**: 억지로 줄이지 않는다. 1–4번은 (가)(나) 조건 상자가 여러 개인 긴 문항만 빼고, 5–8번은 원문 정도 길이면 된다(너무 긴 것만 피함). 1–8번 모두 개념 판단 1개(등호, 범위, 단조성, 좌·우극한, 부호, 그래프 읽기 등)가 핵심이고 계산은 짧게 한다(front.md '1–8번 공통').
- **번호대별 변형 강도**: front.md 0-8 표대로 한다. 1–12번은 같음·쉬워짐, 13–16번은 어려워짐 1–2개, 17·18·서답형2는 0-4. 복습형 회차는 분석집 문항에서만 분석집 TIP 함정을 쓴다.

+def number(raw):
+    raw = str(raw).replace(' ', '')
+    m = re.fullmatch(r'(-?)\\(?:dfrac|frac)\{?(\d+)\}?\{?(\d+)\}?', raw)
+    if m:
+        return (-1 if m[1] else 1) * s.Rational(m[2], m[3])
+    return s.Rational(raw)

+def check(n, result, expected, mistakes):
+    it = ITEMS[n]
+    vals = list(map(number, it['choices']))
+    assert len(vals) == len(set(vals)) == 5
+    assert len(set(vals[i + 1] - vals[i] for i in range(4))) == 1
+    assert vals[1] > vals[0]
+    assert it['ans'] == expected and result == vals[expected - 1]
+    assert vals.count(result) == 1
+    assert set(it['wrongs']) == set(mistakes)
+    for text, value in mistakes.items():
+        assert text in it['choices'] and number(text) == value != result
+    assert it['author'] == 'codex'
+    print(f'{n}: answer={result}, index={expected}, choices/wrongs OK')

+def original(key, result):
+    _, choices, answer, _ = F.I[key]
+    want = number(choices['①②③④⑤'.index(answer)]) if answer in '①②③④⑤' else number(answer)
+    assert result == want, (key, result, want)
+    print(f'ORIGINAL {key}: {result} OK')

+# 1: the two independent equations uniquely fix a and b; derivative signs
+# distinguish the maximum from the minimum.
