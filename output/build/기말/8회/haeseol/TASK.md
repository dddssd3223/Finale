# 8회 해설 다시 쓰기 (샘플 해설지 문체·구성)

양정고 2학년 미적분Ⅰ 기말 모의고사 8회의 학생용 해설을 시판 모의고사 해설지 형식으로 다시 쓴다.

## 샘플 (반드시 먼저 볼 것)
`/root/.claude/uploads/12e2698e-3f00-52d2-bb21-f0ec4f5dc473/828dcb11-2027_______________________3______.pdf`
- Read 도구로 `pages: "8-9"`(구성 요소 설명), `pages: "14-20"`(실제 해설), `pages: "25-27"`(어려운 문항: 실전 개념·논리적 정당화·CHECK 각주)를 본다.
- 문체: "~하자.", "~이다.", "~을 알 수 있다.", "이제 ~을 구하자." 식이 짧은 문장 + 가운데 정렬 식 덩어리. 식 덩어리 안에서 다음 줄은 "→"로 잇고, 이유는 "(∵ …)", 결론은 "∴".
- 해법 꼬리표: 교과서 개념만 쓰면 "교과서적 해법", 실전 개념(교과서 밖 요령)을 쓰면 "실전적 해법".
- 실전 개념/교과서 개념 상자: 그 풀이에 쓰이는 개념이 있을 때만 1–2개(제목 + 짧은 설명·식).
- 논리적 정당화: 직관적으로 넘어간 단계(★ 표시)를 엄밀히 확인하는 짧은 단락. 필요한 문항만.
- CHECK 각주: 본문에서 짧게 넘긴 보충 설명(본문에 1) 같은 번호). 필요한 문항만.
- 생각의 시작: 문제를 보고 가장 먼저 해야 할 생각 한두 문장(9번 이후 문항에 권장).
- STEP 흐름 정리: 13번 이후와 서답형2에만, 2–4단계(제목 + 핵심 한두 줄).

## 문체 규칙 (사용자 2026-11-23, 가장 우선)
- **모든 문장은 '-다.'로 끝낸다.** 본문·생각의 시작·STEP 항목·논리적 정당화·개념 상자 설명·변형 포인트까지 전부. '~임', '~함', '~것', '~할 것' 같은 명사형 끝맺음 금지, '~습니다'도 금지.
- **괄호 금지.** 글 속 설명 괄호 '(∵ …)', '(C는 적분상수)', '(단, …)', '(i)' 같은 것을 쓰지 않는다. 이유는 '~이므로', '~이기 때문이다' 문장으로 풀어 쓴다. 경우 나누기는 '첫째, ~이다.' '둘째, ~이다.' 또는 ㉠ ㉡로 쓴다. 수식 안의 함수 표기 \(f(x)\), 좌표 \((1,\ 2)\), 구간 \([0,\ 3]\)처럼 수학 기호로 꼭 필요한 괄호만 허용한다. 수식 안에 \text{(∵ …)}를 넣지 않는다.
- **CHECK 각주 없음.** notes는 빈 목록 []으로 두고, 꼭 필요한 보충은 본문 문장으로 넣는다. <sup>1)</sup> 표시도 쓰지 않는다.
- STEP 항목(points)도 '-다.'로 끝나는 완결 문장으로 쓴다. STEP 제목은 짧은 명사구로 써도 된다.

## 할 일 (맡은 번호마다)
1. 기존 sol·fast·wrong을 읽고 직접 풀어 확인한다(sympy 확인 권장). 답은 바꾸지 않는다. 기존 풀이가 틀렸으면 보고에 적는다.
2. 샘플 문체로 해설을 새로 쓴다. 기존 sol 문장을 옮기지 말고, 학생이 따라가기 쉬운 순서로.
3. 변형 포인트(학생용): 부교재 원문이 무엇을 물었고, 어디를 어떻게 바꿨고, 그래서 새로 필요한 판단이 무엇인지. 내부 기록(DB, GEN/LIVE id, OP 번호, N제, dupcheck, 조작_보강 같은 칸 이름)은 쓰지 않는다.
4. 오답 선지 함정은 필요하면 본문 끝 문장 하나로 쓴다.
