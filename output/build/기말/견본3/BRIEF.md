## 결과물 (자기 담당 파일만 쓴다. 다른 파일은 고치지 않고, git commit도 하지 않는다)
- `parts/pN.py`
  - 선택형: `ITEMS = {번호: dict(body, cond, bogi, after, choices, ans, key, src, var, level, sol, fast, note, wrong)}`
    - `cond=[('가', r"..."), ...]`: 라벨 없는 상자는 `('', r"...")`, 상자가 없으면 키를 뺀다.
    - `bogi=[('ㄱ', r"..."), ...]`: <보기> 문항에서만 쓰고, 이때 `choices=['T:ㄱ', 'T:ㄱ, ㄴ', ...]`로 적는다.

    - `level`: 변형 후 난도, '하/중/중상/상/최상' 중 하나.
    - `sol`: 학교 해설식 풀이. `fast`: 빠른 풀이.

  - 서답형: `SITEMS = {'S1': dict(body, cond, after, subs=[(질문, '4점, 풀이과정을 상세히 쓰시오.'), ...], ans=[...], rubric=[...], sol=[...], fast, wrong, note, key, src, var, level)}`

## 작성 규칙 (사용자가 여러 번 지적한 것)
- **수식 표기**
  - 수식은 `\( \)`(KaTeX), 가운데 줄 수식은 `\[ \]`로 쓴다. HTML 안에서 `<`는 `&lt;`로 쓴다.
  - 조각함수·부등식·관계식은 가운데 줄로, 짧은 정의는 문장 안에 쓴다.
- **군더더기**: 쓸데없는 괄호 설명, 답이 바뀌지 않는 단서, '(자체 제작)' 같은 표기는 넣지 않는다.
- **말투**: 자료식 말투(0-6)를 쓴다. '속한다', '생각하자', '~마다', '중근' 같은 말은 쓰지 않는다.
- **선지**
  - 5개 등차 배열로 둔다. 기본은 공차 1이고 2, 5, 1/2 등도 쓸 수 있다.
  - 오답 근거 값이 배열 안에 들어가도록 공차와 시작값을 고른다.
  - 원문이 단답형이면 5지선다로 바꾼다.
  - 13번 이상에서 답이 분수가 나오면 상수배를 붙이거나 묻는 양을 바꿔 정수로 만든다.
- **질문 위치**: 조건 상자가 있으면 '…가 다음 조건을 만족시킬 때, ~의 값은?' 다음에 상자를 둔다.
- **함수 소개 순서**: 함수·미정계수는 첫 문장에서 소개한다.
- **중복 금지**: 익스텐션·분석집과 같은 문항은 금지다. 숫자만 바꾼 출제는 1–16번에서는 허용되지만, 17·18·서답형2에서는 허용되지 않는다.
- **평가 요소 유지**: 어느 번호든 원문이 재는 단원 핵심 개념(극한·연속, 미분가능성, 넓이 등)은 바꾸지 않는다. 바꾸는 것은 설정·원리·수치이고 주제는 그대로 둔다.
- **출제 범위**: 미적분Ⅰ 다항함수만 쓴다. 넓이는 \(y=f(x)\) 그래프를 \(x\)로 적분해 구한다. \(x=g(y)\) 꼴 곡선, 이차곡선, \(y\)에 대한 적분, 지수·로그·삼각함수는 금지다(front.md 0-1-1).
- **그림 수치**: 풀이에 쓰는 좌표·길이·값은 본문에 쓰고, 그림은 모양 확인용으로만 쓴다.
- **앞번호는 짧고 무겁게**: 1–8번은 문장 2–3줄 이내로 쓰고, 개념 판단 1개(등호, 범위, 단조성, 좌·우극한, 부호, 그래프 읽기 등)를 핵심으로 한다. 계산이 길어서 무거우면 안 된다(front.md '1–8번 공통').
- **번호대별 변형 강도**: 1–8번은 숫자·조건 변경 위주로, 9–14번은 지침 해당 절대로 바꾼다. 15–16번은 조건 변경, 함수 교체, 함정을 쓴다. 17·18·서답형2는 0-4 기준을 먼저 적용하고, 익스텐션·분석집은 도구로만 쓴다.
